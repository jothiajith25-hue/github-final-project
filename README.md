Simple Interest Calculator

📖 Overview

The Simple Interest Calculator is a basic web application that helps users quickly calculate interest based on the principal amount, rate of interest, and time period. It is designed with a clean user interface and easy-to-use input fields for a smooth user experience.

🚀 Features

Calculate simple interest instantly
User-friendly interface
Input validation for accurate results
Responsive design (works on desktop & mobile)
Real-time result display

🧮 Formula Used

Simple Interest is calculated using the formula:

Simple Interest=
100
P×R×T

Where:

P = Principal amount
R = Rate of interest (per annum)
T = Time (in years)
